# ECG-Signal-Processing
# Traitement du Signal ECG

Petit projet d’apprentissage créé pour démontrer mes compétences de base en Python et en MATLAB.

## Objectif

Ce projet me permet de pratiquer les notions fondamentales de programmation et de mathématiques appliquées, en explorant le traitement des signaux ECG. Il s’inscrit dans mon parcours de préparation pour une candidature en licence (L1) via Campus France.

## Ce que j’ai pratiqué

- Les bases du langage Python
- La manipulation de données numériques
- Les opérations mathématiques de base
- La visualisation de signaux
- Les notions de base du logiciel MATLAB, via MATLAB Onramp

## À propos du projet

Il s’agit d’un projet éducatif et personnel, destiné à montrer mon intérêt pour la programmation, les mathématiques et le traitement du signal. Ce n’est pas un projet médical ou professionnel complet, mais une première étape dans mon apprentissage.

## Outils utilisés

- Python
- MATLAB Onramp

## Remarque

Ce projet est encore un exercice d’apprentissage et peut évoluer au fur et à mesure de mon développement.
