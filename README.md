# ECG-Signal-Processing
Simulation et traitement numérique d'un signal ECG avec Python

Un projet personnel visant à explorer les principes fondamentaux du traitement numérique du signal à travers la simulation d'un signal électrocardiographique. Il consiste à générer un signal artificiel, simuler des perturbations électriques, appliquer un filtre numérique et détecter les pics caractéristiques afin d'estimer la fréquence cardiaque.

Technologies : Python, NumPy et Matplotlib.
